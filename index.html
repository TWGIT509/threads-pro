智慧分流管理中心

雲端管理多個活動、活動頁與 LINE 目的地；新增活動時可同步建立專屬分流規則。

新增活動時可一次填入活動頁、LINE 與品牌關鍵詞，系統會在 Supabase 建立活動並自動建立專屬分流規則；既有活動、審核及發布紀錄均保留。Threads 自動搜尋需另行取得官方 API 權限並完成排程；本頁不會假裝已自動抓取或自動發布。

① 搜尋關鍵詞

設定搜尋詞、分類及排程間隔。

② 活動與目的地

每個活動可獨立設定活動頁、LINE、品牌關鍵詞及有效期間；資料直接儲存至 Supabase。

③ 智慧分流規則

每個活動可有多個關鍵詞規則；系統先比對分類，再依命中詞數與優先級排序。

④ 貼文匯入與人工確認

可先貼入公開貼文網址及文字；系統依已啟用規則提供活動建議，必須人工確認後才建立追蹤資料。

連線設定

設定 Supabase 專案，啟用雲端登入、同步及 AI Edge Function。

Supabase URL 與 anon key 可用於前端；AI Provider API Key 必須只存放在 Supabase Edge Function Secrets，切勿填入此頁。

Supabase 連線

設定會保存在此瀏覽器。正式環境仍需套用 SQL、啟用 RLS、部署 Edge Function。
